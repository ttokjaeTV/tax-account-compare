# 증권사 절세계좌 수수료 비교표

국내 13개 증권사의 **중개형ISA · 연금저축계좌 · IRP** 수수료를 각 사 공식 공시에서 그대로 옮겨 한 표에 정리했습니다.

👉 **[비교표 열기](https://ttokjaetv.github.io/tax-account-compare/)**

## 현재 데이터 기준일

**2026년 8월 20일** · 비대면 신규 개설 · 온라인 주문 기준

## 담고 있는 것

- 중개형ISA 온라인 매매수수료 (표기 요율 / 유관기관제비용 포함 여부 / 실부담)
- 연금저축계좌 ETF 온라인 매매수수료
- IRP 운용관리 · 자산관리 수수료 (적립금 구간별) 와 면제 조건
- IRP 적립금별 연간 관리수수료 계산
- 계좌별 세제 혜택 · 납입한도 · 연금 수령 세율
- 계좌별 투자 가능 상품 범위
- 증권사별 공식 확인 링크

## 읽기 전에

- **지금 계좌를 새로 여는 경우** 기준입니다. 이미 보유 중인 계좌는 개설 시점의 이벤트 회차 · 계좌관리점 · 신청 이력에 따라 요율이 다릅니다.
- `확인필요` 표시는 **공식 페이지에서 확인하지 못했다는 뜻**이며, 해당 항목이 없다는 뜻이 아닙니다.
- 실부담은 표기 요율에 유관기관제비용(주식 0.0036396% / ETF·ETN 0.0042087%)을 더한 값입니다.
- 세제 수치는 2026년 8월 20일 현재 **시행 중인 법령** 기준입니다. **ISA 납입한도 상향안은 시행되지 않았습니다.**
