매일 아침 8시 20분(KST)에 두 가지를 확인해, 해당되면 **GitHub Issue로 알려주는** 워커입니다.

| 축 | 무엇을 | 왜 |
|---|---|---|
| ① 요율 지문 | 증권사 8곳 수수료·퇴직연금 공시 페이지의 수치 집합 | 자주 안 바뀌지만 **바뀌면 표 여러 줄이 함께 움직입니다** |
| ② 만료 캘린더 | 절세계좌 이벤트·우대 종료일 | **오탐이 없습니다.** 날짜 기반이라 확실합니다 |

## 감지만 합니다. 표를 자동으로 고치지 않습니다.

절세계좌는 **숫자만으로 판단할 수 없는 맥락**이 비교의 핵심입니다.

- 유관기관제비용이 **포함인지 별도인지** — 표기 요율이 같아도 실부담이 다릅니다
- 우대가 **자동인지 신청 필수인지** — 신한투자 ISA는 신청 여부로 50배가 갈립니다
- 면제가 **개인부담금만인지 계좌 전체인지** — 퇴직금을 옮기는 분에게는 결정적입니다
- 우대가 **몇 년 개설분 한정인지** — "평생우대"라도 가입 기간이 정해져 있습니다

그래서 워커는 "뭔가 바뀌었다"까지만 알리고, 실제 갱신은 사람이 공식 안내를 확인한 뒤 실행합니다.

## ① 요율 지문

각 페이지에서 **요율로 보이는 수치(0.0005 ~ 0.95 사이 소수)** 를 뽑아 집합으로 비교합니다.
HTML 구조를 파싱하지 않으므로 마크업이 바뀌어도 잘 깨지지 않습니다.
매매수수료(`0.0036396`)와 IRP 관리수수료(`0.15`)가 같은 패턴에 함께 잡힙니다.

`tier: 1`은 바뀌면 표 여러 줄이 함께 움직이는 곳입니다. 변하면 이슈 제목에 🚨가 붙습니다.

| tier | 대상 | 왜 |
|---|---|---|
| 1 | 미래에셋·하나 퇴직연금 공시 | IRP 운용·자산관리 수수료 원본 |
| 1 | NH나무 수수료 | ISA 우대율(0.0043319 · 0.0049010)이 여기 실립니다 |
| 1 | 삼성증권 수수료 | ISA 평생혜택 요율과 연금저축 무료 문구가 함께 있습니다 |
| 2 | 신한·대신·카카오페이·한국투자 수수료 | 절세계좌 준용 요율의 근거 페이지 |

### 감시하지 않는 곳과 이유

| 대상 | 이유 |
|---|---|
| 신한투자 퇴직연금 공시 | 수치를 JS로 주입해 서버 요청으로는 0개 수집 |
| 키움증권 | WAF가 서버측 요청을 차단 |
| 메리츠증권 매매수수료 | 인증을 요구해 비로그인 접근 불가 |
| KB증권 퇴직연금 수수료 | PDF 공시라 숫자 지문 방식이 맞지 않음 |
| 절세계좌 이벤트 페이지 | 회차마다 URL이 바뀝니다 → ② 만료 캘린더로 대체 |

> **알림이 없어도 분기마다 전수 확인이 필요한 이유**가 이것입니다. 감시 범위가 절반입니다.

- **미래에셋·삼성·대신 ISA 평생우대** — 2026.12.31 **개설** 마감
- **2027년 시행 세법** — 12월 국회 의결. ISA 한도 상향이 다시 올라오는지
